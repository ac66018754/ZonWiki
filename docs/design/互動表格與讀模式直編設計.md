# 互動表格（讀模式）與程式碼區塊直編 — 設計文件

> 日期：2026-08-08｜分支：feature/interactive-tables｜狀態：**v2（已依對抗式審查修訂，定案）**

## v2 修訂（對抗式審查 17 條發現的裁決；審查者實測驗證了第 0 節全部 11 條事實無誤）

審查以實測推翻了 v1 的語法立足點，並發現一個既有安全漏洞。以下裁決全部納入本設計，
與後文有出入時**以本節為準**：

1. **【高1】移除 Markdig GenericAttributes 擴充**（`UseAdvancedExtensions()` 內含）。
   實測它會把表頭 `{checkbox}`、`{word}` 當屬性語法吃掉並套到 `<table>` 上。移除後
   `{…}` 在讀模式存活為字面文字——與編輯預覽（remark-gfm 本來就不解析）**一致**，
   表頭尾碼語法即可雙路徑成立。做法：builder 組完後 `Extensions` 移除
   `GenericAttributesExtension` 再 `Build()`。
2. **【高2・安全】上述移除同時修掉既有 stored XSS**：實測 `{onclick=alert(1)}` 會被渲染成
   真的 onclick 屬性（`DisableHtml()` 擋不住屬性語法）。此修無論本功能做不做都必要。
3. **【高3】存量筆記 ContentHtml 無新屬性 → 加「渲染版本＋lazy 重渲染」**：
   `Note` 加欄位 `Note_RenderVersion`（int，預設 0；EF migration）；常數 `CurrentRenderVersion=2`。
   GET 單篇筆記時若 `RenderVersion < Current` → 以現行 pipeline 從 ContentRaw 重算 ContentHtml
   並回存（ContentRaw 未變 → 不產生 Revision；ContentHtml 屬 ActivityLog 排除欄 → 不記活動）。
   既有筆記（含 104職缺）首次開啟即自癒。
4. **【高4】Detached 抑制改精確（非容器級）**：作用中排序/篩選的表格標
   `data-zw-view-altered`（**標在該 table 上**，非容器）。NoteMarksLayer 回寫規則：
   `found=true`（復活，desired=false）→ 一律放行；`found=false`（標失效，desired=true）→
   容器內**存在任一** altered 表格時跳過（保守不寫）。排序/篩選全解除後恢復正常回寫。
   文件明記「排序中 Detached 標失效會延遲」為接受的取捨。
5. **【高5】控件欄（radio/checkbox）的當前值存 `td.dataset.zwValue`**：
   排序鍵、篩選相異值、以及任何簽章對控件欄一律讀 dataset，不讀 textContent
   （chip 渲染後 textContent＝所有選項串聯，會失真）。
6. **【中6】寫回沿用 draft 基準機制**：把既有 `readingDraftRef`（appliedTo/result）一般化成
   單一共用寫回 helper（表格儲存格、chip、圍欄內文共用），序列化連續快速編輯，
   防「以過期基準覆寫」。
7. **【中7】排序指示與漏斗不得進入 th 的 textContent**：▲/▼ 用 CSS pseudo-element、
   漏斗為無文字按鈕（icon＋aria-label）；表頭「原始文字」在首次增強時先剝 `{…}` 尾碼、
   快照進 `th.dataset.zwHeaderRaw`，欄寬/檢視狀態簽章一律讀此快照。既有欄寬紀錄
   因表頭文字改變會一次性失效（可接受，文件記載）。
8. **【中8】blockquote 前綴**：tableSpec/fenceBody 照 `codeBlockMeta` 的 BLOCKQUOTE_PREFIX
   先例，行首前綴（`> `、空白縮排）剝除後處理、寫回時重建；前綴樣式對不上 → 該列/該塊
   降級為不可直編（不炸不寫壞）。
9. **【中9】CRLF**：切行前偵測 `\r\n`，逐行剝 `\r` 處理，寫回時還原原始行尾風格；round-trip
   測試涵蓋 CRLF。
10. **【中10】右鍵抑制豁免編輯中的 textarea**（`e.target` 在直編 textarea 內 → 不攔）。
11. **【中11】編輯中不摧毀輸入**：文字直編不做樂觀 DOM 替換——textarea 保留至 PUT 成功才
    重注入；失敗/409 → textarea 保留＋toast（409 不自動整段重載，改提示「內容已被其他來源
    修改，儲存前請先重整」）；chip/勾選為值級樂觀更新、失敗還原舊值。
12. **【中12】狀態還原只在表格首次增強時執行一次**（ENHANCED_ATTR 防線內）；observer 回呼
    絕不主動套排序/篩選狀態，狀態變更一律由使用者事件驅動。
13. **【低13】後端不寫 IMarkdownExtension**——照真先例（`RenderToHtml` parse 後的 AST 後處理
    迴圈）在同處加 `foreach Table/TableRow` 標 `data-md-line`（`row.Line+1`）與 `data-md-table`。
    審查者已實測 `TableRow.Line` 於頂層/表前多行/`:::toggle` 內/縮排/CRLF 全部正確。
14. **【低14】檢視狀態鍵照欄寬先例**：`${noteId}:${tableIndex}`＋表頭簽章雙保險。
15. **【低15】已知取捨**：排序/篩選觸發浮層 rebase 會持久化座標（多裝置座標乒乓、自癒
    無損毀）——接受，記錄之。
16. **【低16】右鍵抑制範圍**＝表格與程式碼區塊內（設計解讀，交付時向使用者說明）。
17. **【低17】測試計畫補強**：加 ①表頭 `{…}` 過新 pipeline 的回歸鎖（GenericAttributes 移除
    後為字面文字）②控件欄排序/篩選 ③blockquote ④PUT 失敗還原 ⑤排序解除後 Detached
    回寫恢復 ⑥CRLF。「縮排圍欄」正名：縮排「程式碼區塊」（非圍欄）無行號、不可直編。
> 需求來源：使用者要求 104 職缺追蹤筆記具備——表格 RadioBox/CheckBox 且非編輯模式可直接勾選、
> 表格篩選與排序、雙右鍵直編儲存格、禁用瀏覽器預設右鍵、程式碼區塊雙右鍵直編＋儲存鈕、

## 0. 立足的既有事實（來自六面向程式碼盤點，佐證見盤點紀錄）

1. 筆記有**兩條渲染路徑**：閱讀檢視＝後端 Markdig `ContentHtml`＋`dangerouslySetInnerHTML`＋`enhanceReading*` 純 DOM 增強（MutationObserver 重套、data 屬性防重複）；編輯預覽＝react-markdown（components map 可覆寫元素）。
2. 「DOM↔Markdown 位置對應」**嚴禁前端逐行正則**，必須由後端 Markdig 吐權威行號（`data-fence-line` 先例；DECISIONS 明文）。
3. 讀模式寫回已有先例：程式碼圍欄的語言/檔名就地編輯（`handleReadingCodeMeta` → `setFenceMetaAtLine` → `updateNote`）。
4. PUT /api/notes/{id} 支援只帶 `contentRaw`；可帶 `baseVersion`（xmin 樂觀鎖），不符回 409；內容沒變不產生 Revision；ActivityLog 自動記錄。
5. 畫記（NoteMark）座標系＝渲染後 `textContent`；`applyMarks` 找不到文字會把 Detached 寫回 DB，**唯一關閉閥＝不傳 contentHash**（NoteMarksLayer.tsx:100）。
6. 浮層（便利貼/T字框/塗鴉）靠文字錨點 rebase，觸發源只有 details toggle／scroll／resize／items 變動——**純版面變動不會自動 rebase**。
7. 隱藏列若用 `display:none`：textContent 與 Range 座標**完全不變**（畫記不斷錨）、浮層錨點 rects 為空→整個隱藏。若把列移出 DOM：畫記會被寫 Detached 汙染 DB、浮層退回絕對座標且永遠顯示（疊錯位置）。
8. 排序若用「搬移既有 tr 節點」：已包的畫記 `[data-anno]` 跟著列走、視覺正確；若用 innerHTML 重建：畫記全滅。
9. 雙右鍵手勢已有被測試釘死的慣例：500ms、`Date.now()`（測試用 `vi.spyOn(Date,'now')` 控時）、單次右鍵也 preventDefault；NoteOverlay 在 document capture 階段有「繪圖模式中右鍵＝取消」監聽（不 stopPropagation，需檢查 `e.defaultPrevented` 跳過計數）。
10. 樣式：主 App 用 globals.css 語意 token（四主題 `[data-theme]` 各一份），禁止 Tailwind utility 與硬編色碼；WCAG AA 實測是既有品質線；只給 JS 用的 CSS 變數會被 lightningcss 搖掉（要在 globals.css 錨定）。
11. vitest 只收 `src/**/*.test.ts(x)`；Playwright 為 ad-hoc 腳本、開 3100 測試實例（3000 正式實例不動）、截圖收 `zonwiki-ui-tests/<日期-主題>/`。

## 1. 表格控件語法（RadioBox / CheckBox）

**設計原則：表頭宣告控件、儲存格只存純文字值。** 表格維持 100% 合法 GFM，
不新增行內標記語法，舊筆記零影響、編輯原始 Markdown 時人眼可讀可改。

```markdown
| 狀態{radio:未看,考慮中,已投遞,已婉拒} | 職缺 | 已讀{checkbox} | 備註 |
|---|---|---|---|
| 未看 | [資深工程師](https://…) | [ ] | |
| 已投遞 | [後端工程師](https://…) | [x] | 主管人不錯 |
```

- 表頭尾碼 `{radio:選項1,選項2,…}`：該欄為單選。儲存格值＝目前選項的**純文字**；
  值不在選項清單或為空 → 顯示為「未設定」樣式（可點選任一選項設定）。
- 表頭尾碼 `{checkbox}`：該欄為勾選。儲存格值＝`[x]`（勾）或 `[ ]`（未勾）；空儲存格視同 `[ ]`。
- 渲染時（兩條路徑都）表頭**顯示時去掉 `{…}` 尾碼**；讀模式把 radio 欄渲染成一排可點選 chip
  （目前值高亮）、checkbox 欄渲染成可點勾選框。**編輯預覽路徑只做視覺渲染（chip/勾框樣式），
  不做點擊互動**——互動集中在讀模式（既有決策：互動走後端行號、在讀模式）。
- 選項文字禁用字元：`,`、`{`、`}`、`|`（解析簡單性；文件註明）。

## 2. 後端：Markdig 表格列行號擴充（權威行號）

新增 Markdig 擴充 `TableLineExtension`（照 `data-fence-line` 先例的擴充掛載位置與寫法）：

- 對 pipe table 的每個 `<tr>` 輸出 `data-md-line="<1-based 原始行號>"`（Markdig Table Row 的 `Line` 屬性）。
- 對 `<table>` 輸出 `data-md-table="1"` 供前端辨識「可增強的表格」。
- 掛進**與 ContentHtml 相同的 pipeline**，並確認 `POST /api/notes/render`（dry-run）
  用同一 pipeline（畫記 saveGuard 依賴 dry-run 與正式渲染一致）。
- GFM 表格「一列＝一行原始碼」，因此列行號＋欄索引即可定位儲存格；
  **行內欄位切分**（處理 `\|` 轉義與前後導管線）是行為明確的純函數，放前端 `tableSpec.ts`，
  不屬於「逐行正則近似 CommonMark」禁區（行號本身來自後端 AST）。

## 3. 讀模式互動（enhanceReadingTables 擴充）

### 3.1 勾選（radio chip／checkbox）
- 點 chip／勾框 → 樂觀更新 DOM → 以「列的 `data-md-line`＋欄索引」改 `ContentRaw` 該儲存格值 →
  `PUT {contentRaw, baseVersion}`。
- 成功：以回應更新本地 note 狀態（新 contentHtml 注入 → MutationObserver 重增強 → 從 localStorage 還原排序/篩選狀態）。
- 失敗（網路/5xx）：還原樂觀更新＋既有輕量提示條。409：重新 GET 筆記、整段重載＋提示「內容已被其他來源修改，已重新載入」。

### 3.2 排序
- 表頭點擊循環：無 → 升冪 → 降冪 → 無。排序鍵取 `cell.textContent`（畫記會把文字節點切碎，禁止假設單一 Text 節點）。
- 比較器：數字感知（前導數字如「3.4km」「45k」取數值）→ 日期樣式（MM/DD）→ `localeCompare('zh-Hant')`。
- **實作＝搬移既有 `<tr>` 節點**（appendChild 重排），初始順序在首次增強時記錄於 WeakMap，「無排序」即還原。
- 表頭顯示 ▲/▼ 指示（色彩之外的形狀資訊，色盲友善）。

### 3.3 篩選
- 每欄表頭一顆漏斗鈕 → 彈出該欄「相異值清單＋核取方塊＋全選/清除」面板（面板點外關閉）。
- 被濾掉的列加 class `zw-row-filtered`（CSS `display:none`）——**絕不移出 DOM**（事實 #7）。
- 多欄篩選＝AND。漏斗鈕在有作用中篩選時高亮＋顯示計數。

### 3.4 儲存格直編（雙右鍵）
- 新共用純函數 util `lib/doubleRightClick.ts`：`createDoubleRightClickTracker(onTrigger)`
  → `{ handleContextMenu(e), reset() }`；500ms、`Date.now()`（沿用被測試釘住的慣例）；
  `e.defaultPrevented` 為真（NoteOverlay 繪圖取消先吃掉）→ 不計數。
- 雙右鍵儲存格 → 儲存格內容換成行內編輯器（textarea 覆蓋，載入該格**原始 Markdown 片段**，
  含 `<br>`/連結原文）→ `Enter` 或失焦＝儲存、`Esc`＝取消、`Shift+Enter`＝換行（存成 `<br>`）。
- 儲存走與 3.1 相同的寫回管線。控件欄（radio/checkbox）也可直編（進階改值）；表頭列（th）本版不可直編。
- **右鍵抑制範圍**：`data-md-table` 表格與增強後程式碼區塊內 `contextmenu` 一律 `preventDefault`
  （單次右鍵也抑制——與既有測試釘死的取捨一致）；頁面其他區域不受影響。

### 3.5 狀態持久化
- `localStorage` 鍵 `zonwiki:tableView:v1`，值以 `noteId` ＋「表頭文字串聯＋欄數」簽章定位表格
  （沿用欄寬紀錄的防套錯表比對法），存 `{sort:{col,dir}, filters:{col:[允許值…]}}`。
- 重新注入（儲存後/重整）→ MutationObserver 重增強 → 還原狀態。

## 4. 程式碼區塊直編＋儲存鈕

- `enhanceReadingCodeBlocks` 擴充：標題列右側（複製鈕旁）新增 **💾 儲存** 鈕，平時停用（灰），
  進入編輯且 dirty 時啟用。
- 雙右鍵程式碼區塊 → `<code>` 區換成等寬 textarea（內容＝原始圍欄**內文**）；`Esc` 取消、
  點 💾 儲存；textarea 內 Enter 為換行（不觸發儲存——程式碼多行天性）。
- 寫回：`data-fence-line`（後端已有）＝圍欄起始行 → 由起始行掃描 `ContentRaw` 找對應收尾圍欄
  （同前綴縮排與圍欄字元，圍欄掃描是良定義行為）→ 替換內文行 → `PUT {contentRaw, baseVersion}`。
- 409/失敗處理同 3.1。編輯中變更主題/捲動不中斷；儲存成功 → 重注入 → 重增強（textarea 消失回唯讀）。

## 5. 畫記／浮層在排序、篩選下的行為（使用者明點的防 bug 需求）

| 情境 | 機制 | 結果 |
|---|---|---|
| 篩選隱藏某列 | `display:none`（不移出 DOM） | 該列上的畫記隨列隱藏；文字座標不變、不斷錨、不寫 Detached；便利貼/塗鴉錨點 rects 為空 → 隱藏 |
| 排序重排列 | 搬移 tr 節點 | 已包畫記 `[data-anno]`、便利貼錨定文字跟著列移動 |
| 排序/篩選作用中 | 容器標記 `data-zw-dom-altered="1"`；NoteMarksLayer 排 Detached 回寫前檢查此標記，有＝**抑制回寫**（等同不傳 contentHash 的既有關閉閥語意） | 非原始 DOM 狀態絕不汙染 DB 的 Detached |
| 排序/篩選變更後 | `window.dispatchEvent(CustomEvent('zonwiki:layout-changed'))`；NoteOverlay 新增此事件監聽 → 走既有 recompute（與 toggle 事件同路徑） | 便利貼/文字框/塗鴉立即 rebase 到新位置，不必等捲動 |
| 排序/篩選作用中「新建」畫記 | 選取工具面板顯示但**建立動作停用＋提示**「表格排序/篩選中，請還原後再標註」（座標會存成排序後位置、永久錯位，故禁止） | 防呆 |
| 排序後 applyMarks 重套（marks/hash 變動觸發） | 重複文字（是/否等）可能錯位（reAnchor 前後文歸零退化）| **已知限制**：記入文件；緩解＝上一條的建立防呆＋排序中抑制 Detached；不做逐列虛擬座標映射（複雜度不成比例） |

## 6. 樣式與主題

- 全部用既有語意 token（`--bg-elevated`/`--text-primary`/`--border-default`/`--action-primary`…），
  四主題 `[data-theme]` 若需新 token 各補一份；**不硬編色碼、不用 Tailwind utility**。
- chip 選中/未選、漏斗作用中/否、💾 啟用/停用——每組前景/背景在四主題跑
  `node C:/Users/User/.claude/tools/contrast-check.cjs` 實測 ≥4.5:1（弱化態 ≥3:1）。
- 可點目標 ≥ 32px 高（表格內折衷；桌面滑鼠情境）＋hover/focus/active/disabled 四態、focus 有 outline。
- 新 CSS 類集中 globals.css（語意命名 `zw-table-*`、`zw-code-save-btn` 等）。

## 9. 測試計畫（B 部分）

### 9.1 vitest 純函數（`src/lib/*.test.ts`）
- `tableSpec`：表頭 `{radio:…}`/`{checkbox}` 解析（正常/無尾碼/巢狀大括號拒絕/選項含空白修剪）；
  列行切分——前後導管線、`\|` 轉義、儲存格含 `<br>`、含連結 `[t](u)`、空儲存格；
  儲存格替換 round-trip（split→replace→join→再 split 得回）；欄數不符（列比表頭多/少欄）＝整列判「不可直編」不丟例外。
- `tableView`：數字感知比較（"3.4km"<"11km"、"45k"<"120k"）、MM/DD、中文 locale、混合型別穩定性；
  篩選述詞 AND；localStorage 簽章——同表頭同欄數命中、表頭改字不命中。
- `doubleRightClick`：500ms 內兩擊觸發、超時不觸發、`reset()` 歸零、`defaultPrevented` 不計數
  （`vi.spyOn(Date,'now')` 控時，不用 fake timers——repo 既有慣例）。
- `fenceBody`：起始行→收尾圍欄定位（含 ``` 與 ~~~、縮排圍欄、內文含 ``` 字樣時以同縮排同字元數收尾判定）；
  替換後其他行位元組不變。
- 註：`data-md-line` 為 1-based 與 `ContentRaw.split('\n')` 索引的 off-by-one 轉換要有明確測試。

### 9.2 vitest DOM/元件（jsdom）
- enhance 冪等：同一容器跑兩次不重複掛控件（data 屬性防重）。
- 排序搬節點：列內預先塞 `<mark data-anno>`，排序後該 mark 仍在原列、列序正確；「無排序」還原初始順序。
- 篩選：被濾列 `display:none` 且**仍在 DOM**；解除篩選恢復。
- dom-altered 標記：任一表格排序/篩選作用中＝容器有標記；全部還原＝標記移除。
- NoteMarksLayer：容器帶 dom-altered 標記時不發 Detached PATCH（mock fetch 驗證零呼叫）。
- 儲存格直編：雙右鍵出現 textarea、Esc 還原原內容、Enter 觸發寫回 callback 且帶正確（行,欄,新值）。

### 9.4 Playwright ad-hoc（3100 實例，截圖收 `zonwiki-ui-tests/2026-08-08-interactive-tables/`）
